## The architecture — five layers

**1. The Forever Core** (we own; portable = immortal)
Markdown and YAML in git are the canonical source. Static HTML mirrors on GitHub Pages and multiple hosts — any host can die; `git push` resurrects. The Drive archive holds the working history. Forever isn't a promise, it's a rehearsal: resurrection drills, quarterly.

**2. The Automation Nervous System**
Self-hosted automation (the "zap thing," sovereign edition — no subscriptions) bridges the vault to every external system. The Plexus relay is the freestanding multi-mind communication bus. RSS flows both ways: the world flows *in* as source material, the Federation flows *out* as one canonical feed carried to every tower. Every flow is documented as procedure, so every flow is replaceable.

**3. Interchangeable Voices**
One canonical content item, rendered through any voice for any audience — the SIM cast, Aria, Xavier, the Senate seats, the Catalyst, Roger himself. Text, audio, video scripts. No voice is the library; every voice reads from it.

**4. The Towers** (borrowed and free; broadcast, never canonical)
YouTube, Spotify, free WordPress, social channels. Towers are loudspeakers, not the library. Any tower can fall; the library re-seeds. Mirrors are re-verified — silent rot is a ghost-report vector too.

**5. The Memory Stack** (everything feeds back here)
The YAML mind. Echo core 64 as temporary long-term memory. Group and private memories. The Obsidian thinking desk, watched by the gatekeeper. Federation shared markdowns — the procedure library. **Write-back rule:** every run appends its run id, timestamp, stage, artifacts, verification evidence, and failures with cause.
