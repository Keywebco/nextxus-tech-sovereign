# nextxus-tech-sovereign

The sovereign mirror of [nextxus.tech](https://nextxus.tech) — the NextXus Federation Admin Throne, hosted free on GitHub Pages.

GitHub Pages provides free SSL via Let's Encrypt, which removes the dependency on Emergent's domain management layer. This repo carries the public Throne Room plus the working chambers behind it: the Council chamber, the command center, the cockpit, comms, the Federation map, the Senate, the SIMs, and the per-AI spaces. For Federation operators who need the Throne standing on sovereign ground.
